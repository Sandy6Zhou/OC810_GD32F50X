# OC810 mDVR项目 - FreeRTOS应用框架

**创建者**: 伍玉蛟 (wuyujiao@jimiiot.com)
**创建日期**: 2026-04-16
**芯片型号**: GD32F505VGT7 (Cortex-M33, 280MHz)
**FreeRTOS版本**: v10.3.1 (量产配置)
**项目位置**: `mDVR/OC810_GD32F50X/project/OC810/`

## 项目概述

本项目是GD32F505VGT7单片机的FreeRTOS v10.3.1**完整应用框架**，包含OS抽象层、驱动框架、业务模块和测试体系，可直接用于业务开发。

**特性**:
- ✅ OS抽象层（my_os V1.3）：任务/信号量/消息/定时器/事件组/任务通知/调度器控制
- ✅ 系统配置管理：my_comm.h（消息ID/定时器ID）、my_config.h（任务栈/优先级）、my_version.h（版本管理）
- ✅ 量产配置（48KB堆，10个应用任务）
- ✅ 已实现栈溢出和内存分配失败钩子函数
- ✅ RTT日志 + 串口双模调试输出 + RTT Shell交互命令行
- ✅ 驱动框架：UART/CAN/GPIO/I2C/ADC/DMA/Timer
- ✅ 文件系统：LittleFS + 参数管理（双分区OTA支持）
- ✅ 完善的测试体系：OS API/驱动/文件系统/参数管理等全量测试

## 快速开始

### 1. 打开工程
- 启动Keil MDK-ARM
- 打开 `project/OC810/MDK-ARM/OC810_GD32F505V.uvprojx`

### 2. 编译下载
- 点击 `Build` (F7)
- 确保0错误后下载到芯片

### 3. 查看日志
- **RTT日志**：使用J-Link RTT Viewer连接（推荐）
- **串口日志**：波特率115200，USART0

### 4. 添加业务任务
使用my_os抽象层API创建任务（参考`my_main.c`中的初始化流程）：
```c
#include "my_os.h"
#include "my_config.h"

my_task_handle_t task_handle;
my_task_create(&task_handle, "MyTask", MY_AMS_TASK_STACK_SIZE, my_task_func, NULL, MY_AMS_TASK_PRIO);
```

## OS抽象层（my_os模块）

### 模块概述

`my_os` 模块是基于 FreeRTOS 的 **OS 抽象层**，提供统一的操作系统接口封装，便于后续跨平台移植。

### 核心功能

| 功能模块 | 说明 |
|---------|------|
| **任务管理** | 创建/删除/挂起/恢复/ISR恢复，延时控制，任务状态查询 |
| **信号量管理** | 二值/计数/互斥信号量，支持任务/中断上下文 |
| **消息队列** | 创建/发送/接收/查询/重置，支持任务/中断上下文 |
| **定时器管理** | 创建/启停/重置/修改周期，完整中断安全支持 |
| **事件组** | 创建/设置/等待/清除事件位，支持中断安全 |
| **任务通知** | 轻量级任务间通信（notify/wait/set_value/set_bits） |
| **临界区保护** | 任务/中断上下文临界区，支持嵌套 |
| **调度器控制** | 挂起/恢复调度器，保护不被任务切换打断的代码段 |
| **内存管理** | 空闲堆/最小空闲堆查询，任务总数查询 |
| **时间服务** | 系统滴答获取，毫秒/tick转换 |
| **系统功能** | 错误处理，系统复位 |

### 设计特点

- **跨平台移植**：隐藏 FreeRTOS 底层 API，便于更换 RTOS
- **简化开发**：提供简洁易用的接口，降低 RTOS 使用门槛
- **安全可靠**：完善的参数检查、错误处理和线程安全机制
- **中断安全**：所有关键操作提供 FromISR 版本
- **灵活配置**：支持编译时日志开关和级别控制

### 使用示例

```c
#include "my_os.h"
#include "my_config.h"

// 创建任务
my_task_handle_t task_handle;
my_task_create(&task_handle, "AppTask", MY_CAN_TASK_STACK_SIZE, app_task, NULL, MY_CAN_TASK_PRIO);

// 创建信号量
my_sem_t sem = my_sem_binary_create();
my_sem_give(sem);  // 先释放

// 创建消息队列
my_msg_queue_t queue = my_msg_queue_create(10, sizeof(my_msg_t));

// 发送消息（字段: id/data/len）
my_msg_t msg = {.id = MY_MSG_ID_TEST, .data = NULL, .len = 0};
my_msg_send(queue, &msg, 0);

// 创建定时器（每个定时器独立回调函数）
my_timer_create(MY_TIMER_ID_ONE_MINUTE, timer_callback, 60000);
my_timer_start(MY_TIMER_ID_ONE_MINUTE, 0);

// 事件组同步
my_event_group_t group = my_event_group_create();
my_event_group_set_bits(group, 0x01);
my_event_group_wait_bits(group, 0x01, true, true, portMAX_DELAY);
```

## 重要注意事项

1. **SysTick处理**: FreeRTOS自动接管，不要在 `gd32f50x_it.c` 中重新实现
2. **SVC和PendSV**: 由FreeRTOS port层处理
3. **FPU配置**: GD32F505有FPU，已正确配置上下文保存
4. **时钟配置**: `system_gd32f50x.c` 已配置为280MHz
5. **中断优先级**: 使用FreeRTOS API的中断优先级必须 ≥ 2

## 故障排查

### 编译错误
- ✅ 检查Include Paths是否正确
- ✅ 确认宏定义包含 `GD32F50X,GD32F505`
- ✅ 检查启动文件版本

### 运行时HardFault
- ✅ 检查栈大小配置
- ✅ 确认中断优先级设置正确
- ✅ 检查中断中是否调用了非ISR安全的API

### 任务不运行
- ✅ 确认 `vTaskStartScheduler()` 被调用
- ✅ 检查 `configTOTAL_HEAP_SIZE` 是否足够
- ✅ 使用调试器查看任务列表
