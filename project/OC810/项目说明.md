# OC810 mDVR项目 - FreeRTOS基础框架

**创建者**: 伍玉蛟 (wuyujiao@jimiiot.com)
**创建日期**: 2026-04-16
**芯片型号**: GD32F505VGT7 (Cortex-M33, 280MHz)
**FreeRTOS版本**: v10.3.1 (量产配置)
**项目位置**: `mDVR_MCU/project/OC810/`

## 项目概述

本项目是GD32F505VGT7单片机的FreeRTOS v10.3.1**干净基础框架**，配置为**量产版本**，已移除所有测试代码，可直接用于业务开发。

**特性**:
- ✅ 干净的FreeRTOS基础框架，无测试代码
- ✅ 量产配置（48KB堆，支持12个任务）
- ✅ 已实现栈溢出和内存分配失败钩子函数
- ✅ RTT日志 + 串口双模调试输出
- ✅ 可直接添加业务任务

## 快速开始

### 1. 打开工程
- 启动Keil MDK-ARM
- 打开 `project/OC810/MDK-ARM/OC810_GD32F505V.uvprojx`

### 2. 编译下载
- 点击 `Build` (F7)
- 确保0错误后下载到芯片

### 3. 查看日志
- **RTT日志**：使用J-Link RTT Viewer连接（推荐）
- **串口日志**：波特率115200，USART0

### 4. 添加业务任务
在 `main.c` 中参考LED任务模板创建新任务：
```c
xTaskCreate(vTaskFunction, "TaskName", STACK_SIZE, NULL, PRIORITY, NULL);
```

## mDVR项目需求

### 通信模块
| 模块 | 接口 | 功能 |
|------|------|------|
| **4G模块** | UART | 1路AMS + 4路业务平台并发，支持AGPS |
| **GPS定位** | UART | NMEA解析、经纬度、速度数据 |
| **视频模块** | UART | NT98323通信、OTA透传 |
| **RS232** | UART | 外部设备交互、工厂测试 |
| **RS485** | UART | 工业总线通信 |
| **CAN车载** | CAN | 车载协议解析、车辆数据 |

### 传感器与IO
| 模块 | 接口 | 功能 |
|------|------|------|
| **GSENSOR** | I2C | 震动/碰撞/急加速检测 |
| **红外遥控** | GPIO+Timer | 遥控信号接收 |
| **按键** | GPIO | 用户输入 |
| **LED** | GPIO x6 | 状态指示 |
| **蜂鸣器** | PWM | 告警、提示音 |

### 存储与升级
| 模块 | 功能 |
|------|------|
| **外部Flash** | SPI 25Q32 (4MB)，文件系统、参数存储 |
| **双分区OTA** | AMS平台OTA + 视频UART透传OTA |
| **BootLoader自救** | APP异常时视频UART OTA救砖 |

### 辅助功能
- **RTT日志**：高速日志输出，不占用串口
- **工厂测试**：RS232自检、版本读取、模块测试
- **看门狗**：外部GPIO喂狗 + 内置FWDG
- **电源检测**：ADC x2 (ACC ON/OFF、欠压保护)
- **低功耗管理**：休眠/唤醒，延长电瓶寿命
- **RTC时钟**：系统时钟同步（网络、GPS校准）

## FreeRTOS配置要点

### 关键配置 (FreeRTOSConfig.h)

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `configCPU_CLOCK_HZ` | 280MHz | 系统时钟 |
| `configTICK_RATE_HZ` | 1000 | 1ms节拍 |
| `configTOTAL_HEAP_SIZE` | 48KB | 动态内存堆 |
| `configMAX_PRIORITIES` | 8 | 最大优先级数 |
| `configCHECK_FOR_STACK_OVERFLOW` | 2 | 栈溢出检测（模式2） |
| `configUSE_MALLOC_FAILED_HOOK` | 1 | 内存分配失败钩子 |
| `configTIMER_QUEUE_LENGTH` | 20 | 定时器队列长度 |
| `configENABLE_FPU` | 1 | 启用浮点单元 |

### 量产配置修改记录

| 配置项 | 原值 | 新值 | 原因 |
|--------|------|------|------|
| `configTOTAL_HEAP_SIZE` | 16KB | 48KB | 支持12个任务 + 4G并发 |
| `configCHECK_FOR_STACK_OVERFLOW` | 0 | 2 | 调试阶段保障稳定性 |
| `configUSE_MALLOC_FAILED_HOOK` | 0 | 1 | 监控内存使用 |
| `configTIMER_QUEUE_LENGTH` | 5 | 20 | 支持多任务定时器并发 |
| `configUSE_STATS_FORMATTING_FUNCTIONS` | 1 | 0 | 节省5KB Flash |
| `configCOMMAND_INT_MAX_OUTPUT_SIZE` | 2048 | 0 | 禁用CLI，节省2KB Flash |

### 中断优先级
- **优先级分组**: 4位抢占优先级
- **系统调用中断优先级**: ≥ 2
- **注意**: 使用FreeRTOS API的中断优先级必须 ≥ 2

## 重要注意事项

1. **SysTick处理**: FreeRTOS自动接管，不要在 `gd32f50x_it.c` 中重新实现
2. **SVC和PendSV**: 由FreeRTOS port层处理
3. **FPU配置**: GD32F505有FPU，已正确配置上下文保存
4. **时钟配置**: `system_gd32f50x.c` 已配置为280MHz
5. **中断优先级**: 使用FreeRTOS API的中断优先级必须 ≥ 2

## 故障排查

### 编译错误
- ✅ 检查Include Paths是否正确
- ✅ 确认宏定义包含 `GD32F50X,GD32F505`
- ✅ 检查启动文件版本

### 运行时HardFault
- ✅ 检查栈大小配置
- ✅ 确认中断优先级设置正确
- ✅ 检查中断中是否调用了非ISR安全的API

### 任务不运行
- ✅ 确认 `vTaskStartScheduler()` 被调用
- ✅ 检查 `configTOTAL_HEAP_SIZE` 是否足够
- ✅ 使用调试器查看任务列表
