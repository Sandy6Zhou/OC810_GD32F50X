## 📖 配置说明

### GPIO 模式说明

| 模式 | 枚举值 | 适用场景 | 功耗 |
|------|--------|---------|------|
| **模拟输入** | `GPIO_MODE_ANALOG` | 未使用引脚、ADC 输入 | 最低 (~0μA) |
| **浮空输入** | `GPIO_MODE_INPUT` + `PUPD_NONE` | 外部有上拉/下拉 | 低 |
| **上拉输入** | `GPIO_MODE_INPUT` + `PUPD_PULLUP` | 按键、传感器输入 | 低 |
| **下拉输入** | `GPIO_MODE_INPUT` + `PUPD_PULLDOWN` | 特殊传感器 | 低 |
| **推挽输出** | `GPIO_MODE_OUTPUT` + `OTYPE_PP` | LED、电源控制 | 低 |
| **开漏输出** | `GPIO_MODE_OUTPUT` + `OTYPE_OD` | I2C、电平转换 | 低 |
| **复用功能** | `GPIO_MODE_AF` | USART/SPI/CAN/Timer | 低 |

### 速度等级说明

| 等级 | 枚举值 | 最大翻转频率 | 适用场景 |
|------|--------|-------------|---------|
| **低速** | `GPIO_SPEED_LEVEL0` | 2MHz | 普通 GPIO、LED |
| **中速** | `GPIO_SPEED_LEVEL1` | 25MHz | UART、I2C |
| **高速** | `GPIO_SPEED_LEVEL2` | 50MHz | SPI、SDIO |
| **超高速** | `GPIO_SPEED_LEVEL3` | 120MHz | 高速 SPI、SDIO |

## 功耗优化总结

### 未使用引脚配置

| 配置模式 | 功耗 | 适用场景 |
|---------|------|---------|
| **模拟输入** | ~0μA | 未使用引脚（推荐） |
| **浮空输入** | ~10μA | 外部有上拉/下拉 |
| **上拉输入** | ~20μA | 需要内部上拉 |
| **推挽输出低** | ~5mA | 输出低电平 |
| **推挽输出高** | ~5mA | 输出高电平 |

**建议**：所有未使用引脚配置为**模拟输入模式**，可降低功耗约 **280μA**（28 引脚 × 10μA）

## 总结

### ✅ 配置要点

1. **GPIO 输出**：推挽输出，低速（2MHz），无上下拉
2. **GPIO 输入**：浮空输入或上拉/下拉，低速（2MHz）
3. **USART/UART**：复用推挽，中速（25MHz），上拉
4. **SPI**：复用推挽，高速（50MHz），无上下拉
5. **I2C**：复用开漏，中速（25MHz），外部上拉
6. **CAN**：复用推挽，中速（25MHz），无上下拉
7. **ADC**：模拟输入，无速度，无上下拉
8. **未使用**：模拟输入，最低功耗

### 🎯 注意事项

1. I2C 引脚必须使用**开漏输出** + **外部上拉**
2. 晶振引脚（PD0/1、PC14/15）禁止配置为 GPIO
3. 调试引脚（PA13/14）禁止修改
4. 未使用引脚必须配置为**模拟输入**降低功耗
5. ADC 引脚禁止开启其他复用功能
