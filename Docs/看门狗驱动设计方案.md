# 看门狗驱动设计方案（WDG Driver）

**版本**：V1.0 | **日期**：2026-07-02 | **作者**：伍玉蛟

---

## 1. 设计目标

- **底层解耦**：应用层不直接调用 GD32 标准库 API（`fwdgt_*` / `wwdgt_*`）
- **独立子系统**：FWDGT 和 WWDGT 各有独立 API，可同时使用，互不干扰
- **职责单一**：驱动层只负责硬件操作，业务逻辑由应用层实现
- **可测试性**：驱动层可独立于应用层进行单元测试

### 功能范围

| 子系统 | 时钟源 | 核心能力 |
|--------|--------|----------|
| FWDGT（独立看门狗） | IRC40K（40kHz） | 超时范围 0.1ms ~ 39 天，独立时钟，一旦启用无法关闭 |
| WWDGT（窗口看门狗） | PCLK1/4096 | 预分频 1~262144（19 级），超时后复位，支持调试暂停 |

### 3.2 功能开关

```c
/* WWDGT 功能开关（1=启用，0=禁用），默认禁用 */
#ifndef DRV_WWDG_ENABLE
```

```c
/* FWDGT 配置 */
typedef struct {
    uint32_t timeout_ms;          /* 超时时间（毫秒） */

/* WWDGT 配置（仅 DRV_WWDG_ENABLE 时可用） */

    uint32_t window_ms;           /* 窗口时间（毫秒），0=无窗口限制 */
```

## 5. 内部实现要点

### 5.1 FWDGT 超时计算

时钟源 IRC40K（40kHz），公式：

```
超时(ms) = (预分频 × 重装载值) / 40
```

> IRC40K = 40kHz，40000/1000 = 40

- 预分频范围：4, 8, 16, ..., 32768（14 级）
- 重装载值范围：0x000 ~ 0xFFF（12 位）
- 根据 `timeout_ms` 自动遍历预分频表，选择使重装载值在有效范围内的最优组合

### 5.2 WWDGT 超时计算

时钟源 PCLK1/4096，再经预分频器分频，公式：

```
tWWDGT = tPCLK1 × 4096 × 2^PSC × (CNT[5:0] + 1)   (ms)
```

其中：
- `tPCLK1` = 1000 / PCLK1_Hz（ms）
- `2^PSC` = 预分频系数，范围 2^0 ~ 2^18（1~262144，19 级）
- `CNT[5:0]` = 计数器低 6 位，实际计数值 = CNT[5:0] + 1

#### 参数计算算法（靠近法）

采用靠近法，从小到大遍历 PSC，实际超时宜大不宜小：

1. **条件 1**：当前分频最大范围（CNT=0x7F）≤ 目标超时 → 范围不够，跳过
2. **条件 2**：单步耗时 > 目标超时 → 1 步即超出，CNT=0x40（最小值）
3. **否则**：计算精确 CNT 值，`CNT = (target - base_tick) / base_tick + 0x3F`

WIN 按时间比例计算：`WIN = 0x3F + (CNT - 0x3F) × window_ms / timeout_ms`

最终校验硬件约束 WIN < CNT，满足则返回配置。

#### 预分频编码

GD32F50x WWDGT 预分频由 PSCH[12:10] + PSCL[8:7] 共 5 位编码，代码通过 `s_wwdg_psc_value_table[]` 查表获取寄存器值（`WWDGT_CFG_PSC_DIVx`），无需手动编码。

| 索引 | 分频值 | 索引 | 分频值 | 索引 | 分频值 |
|------|--------|------|--------|------|--------|
| 0 | 1 | 7 | 128 | 14 | 16384 |
| 1 | 2 | 8 | 256 | 15 | 32768 |
| 2 | 4 | 9 | 512 | 16 | 65536 |
| 3 | 8 | 10 | 1024 | 17 | 131072 |
| 4 | 16 | 11 | 2048 | 18 | 262144 |
| 5 | 32 | 12 | 4096 | | |
| 6 | 64 | 13 | 8192 | | |

#### 窗口模式

- `window_ms=0`：无窗口约束，WIN=0x40，喂狗条件 CNT > 0x40 在有效范围内恒成立，等效任意时刻可喂狗
- `window_ms>0`：WIN 按时间比例计算，喂狗条件为 CNT > WIN，过早（CNT > WIN）喂狗被拒绝或触发复位，过晚（CNT < 0x40）触发复位
- CNT 有效范围：0x40 ~ 0x7F（7 位，向下递减至 0x3F 触发复位）

## 6. 应用层示例

### 6.1 仅使用 FWDGT

```c
void vWdgTask(void *pvParameters)
{
    drv_fwdg_config_t cfg = {
        .timeout_ms = 2000,
        .stop_in_debug = true
    };
    drv_fwdg_init(&cfg);

    while (1) {
        drv_fwdg_feed();
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

### 6.2 同时使用 FWDGT + WWDGT

```c
void vWdgTask(void *pvParameters)
{
    drv_fwdg_config_t fwdg_cfg = {
        .timeout_ms = 2000,
        .stop_in_debug = true
    };
    drv_fwdg_init(&fwdg_cfg);

    drv_wwdg_config_t wwdg_cfg = {
        .timeout_ms = 500,
        .window_ms = 0       /* 无窗口约束，任意时刻可喂狗 */
    };
    drv_wwdg_init(&wwdg_cfg);

    while (1) {
        drv_fwdg_feed();
        drv_wwdg_feed();
        vTaskDelay(pdMS_TO_TICKS(300));
    }
}
```

## 7. 注意事项

| 项目 | FWDGT | WWDGT |
|------|-------|-------|
| 启用后可关闭 | 否，只能复位 | 是 |
| 时钟源 | IRC40K（独立） | PCLK1/4096（依赖主时钟） |
| 主时钟失效时 | 仍能工作 | 无法工作 |
| 喂狗约束 | 两次间隔 ≥ 7 个 IRC40K 周期 | window_ms=0 时超时前喂狗即可；window_ms>0 时需在 CNT > WIN 时喂狗 |
| 调试模式 | DBG_FWDGT_HOLD | DBG_WWDGT_HOLD |
