## 一、模块概述

安全内存管理模块基于FreeRTOS的`pvPortMalloc`/`vPortFree`，提供统一的内存分配、释放和监控接口，增强系统健壮性。

**文件位置**: `project/OC810/code/utility/my_mem.h` / `my_mem.c`

---

## 二、核心功能

### 2.1 已实现功能

| 功能 | 说明 | 接口 |
|------|------|------|
| **安全分配** | 分配失败时输出错误日志并返回 | `MY_MALLOC(ptr, size)` |
| **安全释放** | 释放前检查空指针，释放后置NULL | `MY_FREE(ptr)` |
| **内存健康检查** | 监控堆使用量，低内存时告警 | `my_mem_check_health()` |
| **内存统计查询** | 获取堆使用信息 | `my_mem_get_stats()` |

### 2.2 设计特点

1. **统一日志输出**：使用MY_LOG接口，输出带位置信息的错误日志
2. **防Double Free**：`MY_FREE`自动将指针置NULL
3. **位置信息追踪**：日志包含文件名和行号
4. **零额外开销**：纯宏定义实现，无RAM占用

## 三、使用指南

### 3.1 基础分配

```c
#include "my_mem.h"

void task_example(void *pvParameters)
{
    uint8_t *buffer = NULL;

    /* 安全分配，失败返回NULL */
    MY_MALLOC(buffer, 256);

    /* 使用 buffer... */

    /* 安全释放 */
    MY_FREE(buffer);
}
```

### 3.2 内存监控

```c
void task_monitor(void *pvParameters)
{
    while (1)
    {
        /* 检查内存健康状态 */
        my_mem_check_health();

        /* 查询内存统计 */
        size_t free_size, min_free;
        uint8_t usage;
        my_mem_get_stats(&free_size, &min_free, &usage);

        vTaskDelay(pdMS_TO_TICKS(60000));  /* 每60秒 */
    }
}
```

## 五、实现细节

### 5.1 SAFE_MALLOC宏

```c
#define MY_MALLOC(ptr, size) \
    do { \
        (ptr) = pvPortMalloc(size); \
        if ((ptr) == NULL) { \
            MY_LOG_E("Alloc failed: %u bytes", (unsigned)(size)); \
        } \
    } while(0)
```

**工作流程**：
1. 调用`pvPortMalloc`分配内存
2. 检查返回指针是否为NULL
3. 失败时输出MY_LOG_E日志（带位置信息）
4. 返回错误值

### 5.2 SAFE_FREE宏

```c
#define MY_FREE(ptr) \
    do { \
        if ((ptr) != NULL) { \
            vPortFree((void *)(ptr)); \
            (ptr) = NULL; \
        } \
    } while(0)
```

**安全特性**：
- ✅ 空指针检查（防止崩溃）
- ✅ 释放后置NULL（防止Double Free）
- ✅ 可重复调用（幂等操作）

### 5.3 内存健康检查

```c
void my_mem_check_health(void)
{
    size_t freeHeap = xPortGetFreeHeapSize();
    size_t minHeap = xPortGetMinimumEverFreeHeapSize();
    size_t totalHeap = configTOTAL_HEAP_SIZE;

    uint8_t usage = (uint8_t)((totalHeap - freeHeap) * 100U / totalHeap);

    if (freeHeap < MY_MEM_CRITICAL_THRESHOLD)
    {
        MY_LOG_E("[MEM] Low heap: %u bytes (%u%% used)", (unsigned)freeHeap, (unsigned)usage);
    }
    else if (freeHeap < MY_MEM_WARN_THRESHOLD)
    {
        MY_LOG_W("[MEM] Heap warning: %u bytes (%u%% used)", (unsigned)freeHeap, (unsigned)usage);
    }

    if (minHeap < MY_MEM_MIN_THRESHOLD)
    {
        MY_LOG_E("[MEM] Critical min heap: %u bytes", (unsigned)minHeap);
    }
}
```

**告警阈值**：
| 条件 | 级别 | 说明 |
|------|------|------|
| freeHeap < MY_MEM_CRITICAL_THRESHOLD (1024B) | ERROR | 剩余不足1KB |
| freeHeap < MY_MEM_WARN_THRESHOLD (2048B) | WARN | 剩余不足2KB |
| minHeap < MY_MEM_MIN_THRESHOLD (512B) | ERROR | 历史最小值不足512B |

## 七、注意事项

### 7.1 编码问题

**当前状态**: ✅ 已修复，文件使用UTF-8编码，头文件注释清晰可读。

### 7.2 命名规范

**当前状态**: ✅ 已统一使用`MY_`前缀命名规范

**接口列表**：
- `MY_MALLOC` - 安全内存分配
- `MY_FREE` - 安全内存释放
- `my_mem_check_health()` - 内存健康检查
- `my_mem_get_stats()` - 内存统计查询

### 7.3 开发建议

1. **必须使用SAFE_MALLOC/MY_FREE**：禁止直接调用`pvPortMalloc`/`vPortFree`
2. **定期检查内存健康**：在监控任务中调用`my_mem_check_health()`
3. **关注日志输出**：分配失败日志表明内存不足，需优化

### 7.4 性能优化

1. **频繁分配的小对象**：考虑使用内存池
2. **大块内存分配**：注意对齐要求
3. **内存泄漏排查**：定期对比`alloc_count`和`free_count`
