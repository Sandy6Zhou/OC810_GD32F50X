# OC810 项目架构概览

本文档提供 OC810 mDVR 项目的高层架构概览。

## 整体架构

```
┌──────────────────────────────────────────────────────────────┐
│                    OC810_GD32F50X 项目根目录                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌─────────────┐  ┌──────────────┐  ┌────────────────────┐  │
│  │  Bootloader │  │     APP      │  │      tools/        │  │
│  │  (裸机)     │  │  (FreeRTOS)  │  │  (合并脚本)        │  │
│  └──────┬──────┘  └──────┬───────┘  └─────────┬──────────┘  │
│         │                │                     │             │
│         └────────────────┼─────────────────────┘             │
│                          │                                   │
│                    共享库层                                  │
│         ┌────────────────┼─────────────────────┐             │
│         │                │                     │             │
│  ┌──────▼──────┐  ┌──────▼───────┐  ┌─────────▼──────────┐  │
```

## 共享库架构

### 共享库清单

```
共享库 (Bootloader + APP)
├── Library/                          ← GD32 标准外设库
│   ├── Firmware/
│   │   ├── CMSIS/                   ← ARM Cortex-M33 核心文件
│   │   └── GD32F50x_standard_peripheral/
│   │       ├── Include/             ← 外设驱动头文件
│   │       └── Source/              ← 外设驱动源文件
│   └── Utilities/                   ← 评估板工具函数
│
└── Third_Party/
    └── Segger_RTT/                  ← RTT 高速日志库
        └── RTT/RTT/
            ├── SEGGER_RTT.c         ← RTT 核心实现
            ├── SEGGER_RTT.h         ← RTT API
            ├── SEGGER_RTT_Conf.h    ← 共享配置文件
            └── SEGGER_RTT_printf.c  ← printf 支持
```

### APP 专用库

```
APP 专用库
├── Third_Party/
│   ├── FreeRTOSv10.3.1/            ← 实时操作系统
│   │   └── FreeRTOS/Source/
│   │       ├── include/            ← FreeRTOS 头文件
│   │       ├── portable/           ← 移植层（GCC/ARM_CM33）
│   │       └── *.c                 ← FreeRTOS 核心源文件
│   │
│   └── littlefs/                   ← 轻量级文件系统
│       ├── lfs.c                   ← LittleFS 核心
│       └── lfs.h                   ← LittleFS API
```

## Keil 工程结构

### Workspace（推荐）

项目根目录下的 `OC810 MDK-workspace.uvmpw` 是 Keil Workspace 文件，可同时管理 Bootloader 和 APP 工程：

- 一个窗口集中管理两个工程
- 快速切换编译目标
- 统一查看编译输出

### Bootloader 工程

```
Bootloader/project/
├── MDK-ARM/
│   ├── Bootloader.uvprojx          ← Keil 工程文件
│   └── output/                     ← 编译输出
│       ├── Bootloader.hex
│       └── Bootloader.bin
│
└── code/
    ├── main.c                      ← 主程序入口
    ├── my_bl_config.h              ← Bootloader 配置
    └── ...                         ← 其他源文件
```

**Include Paths**:
```
..\..\Library\Firmware\CMSIS
..\..\Library\Firmware\CMSIS\GD\GD32F50x\Include
..\..\Library\Firmware\GD32F50x_standard_peripheral\Include
..\..\Third_Party\Segger_RTT\RTT\RTT
```

### APP 工程

```
project/OC810/
├── MDK-ARM/
│   ├── OC810_GD32F505V.uvprojx     ← Keil 工程文件
│   └── output/                     ← 编译输出
│       ├── Project.hex
│       └── Project.bin
│
└── code/
    ├── app/                        ← 应用层
    ├── driver/                     ← 驱动层
    ├── utility/                    ← 工具层
    └── ...
```

**Include Paths**:
```
..\..\..\Library\Firmware\CMSIS
..\..\..\Library\Firmware\CMSIS\GD\GD32F50x\Include
..\..\..\Library\Firmware\GD32F50x_standard_peripheral\Include
..\..\..\Third_Party\Segger_RTT\RTT\RTT
..\..\..\Third_Party\FreeRTOSv10.3.1\FreeRTOS\Source\include
..\..\..\Third_Party\FreeRTOSv10.3.1\FreeRTOS\Source\portable\GCC\ARM_CM33_NTZ\non_secure
..\..\..\Third_Party\littlefs
```

## IAP 跳转流程

```
┌─────────────────────────────────────────────────────────────┐
│                      启动流程                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  上电复位                                                   │
│     ↓                                                       │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  Bootloader (0x08000000)                             │  │
│  │  1. 初始化时钟、RTT                                  │  │
│  │  2. 检查 OTA 标志 (bootconf)                         │  │
│  │  3. 如果有 OTA 固件，执行升级                        │  │
│  │  4. 跳转到 APP (0x08040000)                          │  │
│  └──────────────────────────────────────────────────────┘  │
│     ↓                                                       │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  APP (0x08040000)                                    │  │
│  │  1. 初始化时钟、RTT（检测已初始化，跳过）             │  │
│  │  2. 初始化 FreeRTOS                                  │  │
│  │  3. 创建任务、驱动、文件系统                         │  │
│  │  4. 启动调度器                                       │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### RTT 连续性保障

```
Bootloader 日志: "Boootloader starting..."
                    "Checking OTA flag..."
                    "Jumping to APP..."
                 ↓ (IAP 跳转，RTT 控制块保留在 RAM)
APP 日志:        "APP starting..."
                    "FreeRTOS initialized..."
                    "All tasks created..."

RTT Viewer 看到: 连续日志（无中断）
```

## 固件构建与合并流程

```
┌─────────────────────────────────────────────────────────────┐
│                    自动化构建流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 编译 Bootloader                                         │
│     └─→ After Build: build_bootloader.bat                   │
│         ├─ 复制 Bootloader.hex → firmware/                  │
│         └─ 复制 Bootloader.bin → firmware/                  │
│                                                             │
│  2. 编译 APP                                                │
│     └─→ After Build: build_firmware.bat auto                │
│         ├─ 复制 Project.hex → firmware/app.hex              │
│         ├─ 复制 Project.bin → firmware/app.bin              │
│         ├─ 合并 HEX → firmware/merged_full.hex              │
│         └─ 合并 BIN → firmware/merged_full.bin              │
│                                                             │
│  3. 烧录 firmware/merged_full.bin 到芯片                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## FLASH 分区布局

```
0x08000000 ┌──────────────────────────┐
           │  mcuboot (48KB)          │
           │  0x08000000~0x0800BFFF   │
           ├──────────────────────────┤
0x0800C000 │  setting_storage (208KB) │
           │  0x0800C000~0x0803FFFF   │
           ├──────────────────────────┤
0x08040000 │  app (376KB)             │
           │  0x08040000~0x0809DFFF   │
           ├──────────────────────────┤
0x0809E000 │  mcu_secondary (376KB)   │
           │  0x0809E000~0x080FBFFF   │
           │  (OTA 固件暂存)           │
           ├──────────────────────────┤
0x080FC000 │  bootconf (4KB)          │
           │  0x080FC000~0x080FCFFF   │
           │  (启动配置/OTA标志)       │
           ├──────────────────────────┤
0x080FD000 │  factory_storage (12KB)  │
           │  0x080FD000~0x080FFFFF   │
           │  (工厂参数/IMEI/MAC)      │
0x08100000 └──────────────────────────┘
           (1MB Flash 结束)
```
